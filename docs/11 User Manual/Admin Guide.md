# Admin Guide

> This is an outline. The full text, with screenshots, is written in M14 in plain English. Most of it is also inside the app as tooltips.

1. **First setup**: the wizard step by step; the recovery code
2. **Staff**: users, PINs, roles and permissions, discount limits, overrides
3. **Products**: adding, barcodes, units, categories, brands, variants, kits, images, archiving
4. **Prices**: price changes, price lists, member tiers, promotions
5. **Tax**: rates, inclusive vs exclusive, what changes affect
6. **Stock**: levels, adjustments, reorder levels, batches and expiry, stock counts
7. **Suppliers and purchasing**: suppliers, purchase orders, receiving goods, supplier returns, paying suppliers
8. **Customers**: credit limits, baki payments, statements, loyalty settings
9. **Labels and shelf tags**
10. **Returns, voids and overrides**
11. **Shifts**: reviewing Z reports, force-closing shifts, cash differences
12. **Reports**: what each report shows; exporting to Excel/PDF
13. **Import and export**: templates, mapping, fixing errors
14. **Settings**: receipt layout, hardware, payment methods, rounding, barcode rules
15. **Backups**: the USB routine, restoring
16. **Audit log and logs**
17. **Updating the app**: [[Installation#Upgrade]]
