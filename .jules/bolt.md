## 2023-10-20 - React Array Allocations and Tree Traversals in Render
**Learning:** In React components, expensive operations like `categoryPaths()` (which does tree traversal and string concatenation) combined with array mapping inside the render function can cause noticeable input lag in controlled text fields, as the field re-renders on every keystroke.
**Action:** When a UI component fetches a list of choices for a picker that involves expensive preprocessing (like constructing tree paths), ALWAYS wrap that preprocessing in a `useMemo` so it's only computed when the choices payload or the translation function actually changes, not on every re-render caused by typing in unrelated filter text boxes. Ensure the dependencies provided to `useMemo` satisfy ESLint's `react-hooks/exhaustive-deps`.
