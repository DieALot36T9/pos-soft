## 2024-05-24 - [Add React.memo to CartTable and ProductCatalogPane]
**Learning:** Found opportunities to prevent unnecessary re-renders in `CartTable` and `ProductCatalogPane`. Both components are likely to be re-rendered frequently as the parent `CheckoutPage` state updates (e.g., ticking the clock, updates to totals, changing the selected item etc.). The checkout screen state changes very often (especially scanning), triggering many top-level re-renders. `React.memo` will optimize this and prevent child re-renders if the props haven't changed.
**Action:** Use `React.memo` for table/list components that receive large arrays as props or take expensive slots and can be relatively expensive to re-render. Also, make sure to use `useCallback` for functions passed as props and `useMemo` for dynamically created JSX passed as slot props to not defeat the memoization.
